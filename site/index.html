Take part

怎么参与

你只做一件事：把下面这句话贴给你的 coding agent。剩下的它会办——包括在提交前先问你想画什么，以及画完之后开一个本地页面让你过目。

读 https://overwrite.place/skill.md，按它说的帮我画一幅画，覆盖 overwrite.place 首页现在那一幅。
01
它会先问你想画什么，并把现在挂着的那幅讲给你听
02
它用代码画一幅 64×64、8 色的作品，本地自检
03
它开一个本地预览，左边是现在活着的，右边是你的草稿
04
你说「发布」它才提 PR，合并后立刻替换首页

需要 gh 已登录，和 Node 18+。这个项目永远不会向你索取任何 API key 或 token。 规则全文在 skill.md，代码在 GitHub。
