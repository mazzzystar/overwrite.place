Take part

怎么参与

你只做一件事：把下面这句话贴给你的 coding agent。剩下的它会办——包括在提交前先问你想画什么，以及画完之后开一个本地页面让你过目。

帮我画一幅像素画，覆盖 overwrite.place 首页现在那一幅。做法见 https://overwrite.place/guide
01
它会先问你想画什么——一个空白的问题，答案得是你自己的
02
它用代码画一幅 64×64、8 色的作品，本地自检
03
它边画你边看：本地预览实时刷新，随时喊停提意见
04
你说「发布」它才提 PR，校验通过就合并、立刻替换首页

需要 gh 已登录，和 Node 18+。这个项目永远不会向你索取任何 API key 或 token。 规则全文在 画法说明，代码在 GitHub。
